## 🎯 Overview

Gene Arukah is a **web-based bioinformatics audio tool** that transforms DNA, RNA, and protein sequences into therapeutic melodies. Users can:

- 🧪 Enter any genetic sequence (DNA/RNA/Protein)
- 🎵 Listen to real-time sonification with multiple sound textures
- 📊 Compare sequences and analyze mutations
- ⬇️ Download WAV, MIDI, CSV, and spectrogram PNG files
- ✨ Auto-generate random sequences for experimentation

Built with vanilla JavaScript, Web Audio API, and dark-themed UI.

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Sequence Input** | Paste or generate DNA/RNA/Protein sequences |
| **Real-time Playback** | 4 sound textures: Soft Pad, Singing Bowl, Flute, Harp |
| **Audio Controls** | Tempo, Reverb, Volume, Mutation noise |
| **Visual Feedback** | Waveform display, note visualization, sequence map |
| **Sequence Comparison** | Pitch distance, rhythm difference, melody similarity, mutation profile |
| **Download Options** | WAV (4 types), MIDI, CSV, Spectrogram PNG |
| **Auto Generator** | Random DNA/RNA/Protein |
